# Personal Portfolio Website

A responsive personal portfolio website showcasing my professional journey, interests, hobbies, and passion for Carnatic music.

**Live Website:** https://srivarshini1810official-gif.github.io/my-personal-portfolio/

## About the Project

This project is a single-page personal portfolio developed using HTML, CSS, and JavaScript. It presents my profile, professional journey, personal interests, and musical activities through a clean and responsive design.

The website follows a dark editorial theme with a minimal and elegant visual style.

## Technologies Used

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layouts, animations, and responsive design.
- **JavaScript** – Interactive features and dynamic behavior.
- **Git** – Version control.
- **GitHub** – Source code hosting and collaboration.
- **GitHub Actions** – CI/CD automation.
- **GitHub Pages** – Website hosting.
- **Lighthouse CI** – Website performance and quality auditing.

## Running the Project Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/srivarshini1810official-gif/my-personal-portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd my-personal-portfolio
   ```

3. Open the project in Visual Studio Code.

4. Open `index.html` using the Live Server extension, or open it directly in your browser.

## CI/CD Pipeline

GitHub Actions automates validation, deployment, quality checks, Lighthouse auditing, and deployment notifications.

| Workflow | Purpose |
|---|---|
| `ci.yml` | Continuous integration checks |
| `validate.yml` | HTML, CSS and JavaScript validation |
| `deploy.yml` | Automatic GitHub Pages deployment |
| `pr-checks.yml` | Pull request quality checks |
| `lighthouse.yml` | Website performance auditing |
| `notify.yml` | Deployment success/failure notifications |

## Branching Strategy

- `main` – Production-ready code.
- `develop` – Integration and development branch.
- Changes are developed and merged through Pull Requests.
